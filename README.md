## Привет! 👋 Меня зовут Светлана, я FullStack-разработчик с фокусом на Java и JavaScript/React

За моими плечами — более 11 лет работы в IT: от технической поддержки и тестирования ПО до аналитики и полноценной разработки. Такой путь дал мне редкое преимущество: я не просто пишу код, а понимаю, как продукт живёт у пользователя, где возникают боли и как сделать систему удобной и надёжной.
Сегодня я закрываю задачи полного цикла.
На backend — создаю сервисы на Java со Spring Boot, проектирую REST API, работаю с PostgreSQL, Redis, настраиваю безопасность (Spring Security + JWT), асинхронную обработку через Kafka и контейнеризацию в Docker.
На frontend — строю современные интерфейсы на React 18 с использованием React Router DOM для маршрутизации, Vite как сборщика и dev-сервера, Bootstrap 5 + React Bootstrap для адаптивного UI и Framer Motion для плавных анимаций. Пишу на современном JavaScript (ES Modules).
Мой подход: чистый код, покрытие тестами (JUnit 5, Mockito, Postman), прозрачная коммуникация и внимание к деталям. В работе активно использую современные LLM-инструменты, что ускоряет разработку и повышает качество решений.
Свободно работаю с технической документацией на англ.яз.
